For each candidate ball, `_best_pocket_shot` computes the cut angle toward each of the 6 pockets (`POCKETS`) using `geometry.cut_angle_degrees`, discards pockets with an angle above `MAX_CUT_ANGLE` (80°) or whose path is blocked by another ball (`geometry.is_path_blocked` checks whether the segment passes within 2 ball radii of another ball, via `point_segment_distance`), and keeps the pocket with the lowest angle among what's left. `_search` does a depth-first search: at each level it orders the remaining balls from easiest to hardest angle, assumes the cue ball comes to rest at the ghost-ball point (`cue_rest_position`, a simplified "stun shot" model), and tries to continue the search from there; if there's no valid continuation for the rest, it backtracks and tries the next candidate. If no ball has a valid shot in a given state, `_search` returns `None`, and `find_runout` turns that into `possible: False`, using `_first_unmakeable_ball` to point at the first ball with no shot at all from the starting position (this doesn't catch deeper sequencing conflicts, which is a deliberate simplification documented in the ADR). |
